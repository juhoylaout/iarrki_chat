A simple AI chatbot using a public language model for question answering.

Requires a Windows 11 operating system and a Python 3 installation.
The program creates a python virtual environment and downloads all necessary packages.
The program uses a language model from Hugging Face, name of which is in the model.txt file.
The model needs to have implementations of classes AutoTokenizer and AutoModelForCausalLM.

Use:
Run the install.bat file by double clicking.
The run the run.bat file by double clicking.
